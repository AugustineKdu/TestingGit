# TestingGit - 앱 개발 테스트 저장소

## 프로젝트 소개
이 저장소는 피그마 연결과 앱 개발 기획을 테스트하기 위해 만들어졌습니다.

## 주요 기능
- 🎨 **피그마 연결**: Figma API를 통한 디자인 토큰 자동화
- 📱 **앱 프로토타입**: React Native 기반 샘플 앱
- 📋 **기획 문서**: 요구사항 명세서 및 기능 정의서
- ✅ **테스트 자동화**: 다양한 테스트 스크립트

## 프로젝트 구조
```
TestingGit/
├── docs/           # 기획 문서
├── figma/          # 피그마 연동 설정
├── app/            # 앱 프로토타입 코드
└── tests/          # 테스트 스크립트
```
