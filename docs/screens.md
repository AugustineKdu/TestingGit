# 화면 설계서

## 1. 화면 구조

### 1.1 내비게이션 구조

```
앱 시작
  ├─ 스플래시
  └─ 인증 확인
      ├─ 로그인 ──┐
      │           │
      └─ 메인 앱 ─┘
          ├─ 홈
          ├─ 검색
          ├─ 알림
          └─ 프로필
              ├─ 설정
              └─ 프로필 편집
```

## 2. 화면 상세 설계

### 2.1 스플래시 화면 (Splash)

#### 화면 요소
```
┌─────────────────────┐
│                     │
│                     │
│      [앱 로고]       │
│                     │
│    TestingGit       │
│                     │
│   로딩 인디케이터     │
│                     │
│                     │
└─────────────────────┘
```

#### 동작
- 앱 실행 시 2초간 표시
- 로고 페이드인 애니메이션
- 인증 상태 확인 후 자동 이동

---

### 2.2 로그인 화면 (Login)

#### 화면 레이아웃
```
┌─────────────────────┐
│      [< 닫기]        │
├─────────────────────┤
│                     │
│   환영합니다! 👋     │
│   로그인해주세요      │
│                     │
│   ┌───────────────┐ │
│   │ 이메일         │ │
│   └───────────────┘ │
│                     │
│   ┌───────────────┐ │
│   │ 비밀번호       │ │
│   └───────────────┘ │
│                     │
│   [비밀번호 찾기]     │
│                     │
│   ┌───────────────┐ │
│   │   로그인       │ │
│   └───────────────┘ │
│                     │
│   ───── 또는 ─────   │
│                     │
│   [🔵 Google 로그인] │
│   [🍎 Apple 로그인]  │
│                     │
│   계정이 없으신가요?  │
│   [회원가입]         │
│                     │
└─────────────────────┘
```

#### UI 컴포넌트
- **헤더**: 닫기 버튼 (회원가입에서 돌아온 경우)
- **타이틀**: "환영합니다!"
- **서브타이틀**: "로그인해주세요"
- **이메일 입력**: 텍스트 필드, 이메일 키보드
- **비밀번호 입력**: 시큐어 텍스트, 보기/숨기기 토글
- **비밀번호 찾기**: 텍스트 버튼
- **로그인 버튼**: 프라이머리 버튼
- **소셜 로그인**: 각 플랫폼 브랜드 버튼
- **회원가입 링크**: 텍스트 버튼

#### 인터랙션
- 입력 필드 포커스 시 하단 바 색상 변경
- 유효성 검사 실패 시 에러 메시지 표시
- 로그인 중 버튼 로딩 상태
- 키보드 나타날 때 화면 스크롤

#### 화면 레이아웃
```
┌─────────────────────┐
│   [< 뒤로]  회원가입  │
├─────────────────────┤

│   │  [카메라] │      │
│   │  아이콘   │      │
│   └─────────┘       │
│   이미지 추가(선택)   │
│                     │
│   ┌───────────────┐ │
│   │ 이메일 *       │ │
│   └───────────────┘ │
│                     │
│   ┌───────────────┐ │
│   │ 닉네임 *       │ │
│   └───────────────┘ │
│                     │
│   ┌───────────────┐ │
│   │ 비밀번호 *     │ │
│   └───────────────┘ │
│   • 8자 이상        │
│   • 영문, 숫자 포함  │
│                     │
│   ┌───────────────┐ │
│   │ 비밀번호 확인 * │ │
│   └───────────────┘ │
│                     │
│   ☑ 이용약관 동의(필수)│
│   □ 마케팅 수신 동의  │
│                     │
```

#### 유효성 검사
- 실시간 입력 검증
- 이메일 중복 확인
- 비밀번호 강도 표시
- 약관 동의 필수 체크

## 3. 공통 UI 요소

### 3.1 버튼

#### 프라이머리 버튼
- 높이: 48pt
- 모서리: 8pt 라운드
- 색상: 테마 primary 색상
- 텍스트: 16pt, 볼드

#### 세컨더리 버튼
- 높이: 48pt
- 테두리: 1pt
- 배경: 투명
- 텍스트: primary 색상

#### 텍스트 버튼
- 패딩: 8pt
- 텍스트: 14pt
- 색상: secondary 색상

### 3.2 입력 필드

#### 텍스트 필드
- 높이: 48pt
- 모서리: 8pt
- 테두리: 1pt
- 패딩: 16pt
- 플레이스홀더: 회색

#### 포커스 상태
- 테두리: primary 색상
- 하단 바: 2pt

#### 에러 상태
- 테두리: 빨간색
- 에러 메시지: 12pt, 빨간색

### 3.3 카드

#### 기본 카드
- 모서리: 12pt
- 그림자: 0 2 8 rgba(0,0,0,0.1)
- 패딩: 16pt
- 배경: 흰색 (라이트) / 다크 (다크 모드)

### 3.4 하단 탭

#### 탭 항목
- 아이콘: 24x24pt
- 라벨: 10pt
- 선택됨: primary 색상
- 선택 안됨: 회색

## 4. 테마

## 5. 애니메이션

### 5.1 화면 전환
- 슬라이드: 300ms ease-out
- 페이드: 200ms ease-in-out
- 모달: 250ms spring

### 5.2 인터랙션
- 버튼 탭: 스케일 0.95, 100ms
- 로딩: 회전 애니메이션
- 스켈레톤: 펄스 효과
