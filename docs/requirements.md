# 요구사항 명세서

## 1. 프로젝트 개요

### 1.1 목적
피그마 디자인 시스템과 연동된 모바일 앱 프로토타입을 개발하여, 디자인-개발 워크플로우를 테스트합니다.

### 1.2 범위
- Figma API를 통한 디자인 토큰 자동화
- React Native 기반 크로스 플랫폼 앱
- 기본적인 사용자 인증 및 프로필 관리
- 샘플 콘텐츠 표시 기능

### 1.3 대상 사용자
- 디자이너: 디자인 시스템 관리
- 개발자: 앱 개발 및 유지보수
- 기획자: 기능 테스트 및 검증

## 2. 기능 요구사항

### 2.1 필수 기능 (Must Have)

#### FR-001: 사용자 인증
- 이메일/비밀번호 기반 로그인
- 소셜 로그인 (Google, Apple)
- 회원가입 및 비밀번호 찾기

#### FR-002: 프로필 관리
- 프로필 정보 조회
- 프로필 이미지 업로드
- 개인정보 수정

#### FR-003: 홈 화면
- 최근 활동 표시
- 추천 콘텐츠 목록
- 빠른 액션 버튼

#### FR-004: 설정
- 앱 테마 변경 (라이트/다크 모드)
- 알림 설정
- 언어 설정 (한국어/영어)

### 2.2 권장 기능 (Should Have)

#### FR-005: 검색
- 키워드 기반 검색
- 최근 검색 이력
- 인기 검색어

#### FR-006: 알림
- 푸시 알림
- 인앱 알림 센터
- 알림 설정 관리

### 2.3 선택 기능 (Could Have)

#### FR-007: 공유
- SNS 공유
- 링크 복사
- QR 코드 생성

#### FR-008: 오프라인 모드
- 캐시된 데이터 표시
- 오프라인 상태 감지
- 동기화 기능

## 3. 비기능 요구사항

### 3.1 성능

#### NFR-001: 응답 시간
- 화면 전환: 300ms 이내
- API 응답: 2초 이내
- 이미지 로딩: 5초 이내

#### NFR-002: 동시 사용자
- 최소 1,000명 동시 접속 지원
- 피크 타임 대응 가능

### 3.2 보안

#### NFR-003: 데이터 보호
- HTTPS 통신 필수
- 민감 정보 암호화 저장
- JWT 기반 인증

#### NFR-004: 개인정보
- GDPR 준수
- 개인정보 처리방침 표시
- 데이터 삭제 요청 지원

### 3.3 사용성

#### NFR-005: 접근성
- WCAG 2.1 AA 수준 준수
- 스크린 리더 지원
- 최소 터치 영역: 44x44pt

#### NFR-006: 다국어
- 한국어, 영어 지원
- RTL 레이아웃 고려
- 지역별 날짜/시간 형식

### 3.4 호환성

#### NFR-007: 플랫폼
- iOS 14.0 이상
- Android 8.0 (API 26) 이상

#### NFR-008: 디바이스
- 스마트폰 (4.7" ~ 6.7")
- 태블릿 대응
- 다양한 화면 비율 지원

## 4. 제약사항

### 4.1 기술적 제약
- React Native 최신 안정 버전 사용
- Node.js 18 LTS 이상
- TypeScript 필수

### 4.2 일정
- 프로토타입 개발: 4주
- 테스트 및 검증: 2주
- 문서화: 1주

### 4.3 리소스
- 개발자: 2명
- 디자이너: 1명
- PM: 1명 (파트타임)
