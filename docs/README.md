# 기획 문서

## 문서 목록

### 1. 요구사항 명세서 (requirements.md)

### 2. 기능 정의서 (features.md)
각 기능의 상세 명세와 사용자 시나리오를 설명합니다.

### 3. 화면 설계서 (screens.md)
앱의 각 화면 구조와 UI/UX를 정의합니다.

### 4. API 명세서 (api-spec.md)
백엔드 API 엔드포인트와 데이터 구조를 정의합니다.

### 5. 데이터베이스 설계 (database.md)
데이터 모델과 스키마를 정의합니다.
