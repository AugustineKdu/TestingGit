# 기능 정의서

## 1. 사용자 인증 (Authentication)

### 1.1 로그인

#### 기능 설명
사용자가 이메일과 비밀번호를 입력하여 앱에 로그인합니다.

#### 사용자 시나리오
```
1. 사용자가 앱을 실행합니다
2. 로그인 화면이 표시됩니다
3. 이메일과 비밀번호를 입력합니다
4. "로그인" 버튼을 탭합니다
5. 인증 성공 시 홈 화면으로 이동합니다
```

#### 입력 요소
- 이메일 주소 (필수)
- 비밀번호 (필수)

#### 유효성 검사
- 이메일 형식 확인
- 비밀번호 최소 8자 이상
- 빈 값 체크

#### 에러 처리
- "이메일 형식이 올바르지 않습니다"
- "비밀번호가 일치하지 않습니다"
- "네트워크 연결을 확인해주세요"

### 1.2 소셜 로그인

#### 지원 플랫폼
- Google 로그인
- Apple 로그인 (iOS 필수)

#### 동작 방식
1. 소셜 로그인 버튼 탭
2. 해당 플랫폼의 인증 화면 표시
3. 사용자 동의 및 인증
4. 토큰 발급 및 자동 회원가입
5. 홈 화면으로 이동

### 1.3 회원가입

#### 필수 정보
- 이메일
- 비밀번호
- 비밀번호 확인
- 이용약관 동의

#### 선택 정보
- 닉네임
- 프로필 이미지
- 마케팅 수신 동의

#### 검증 규칙
- 이메일 중복 체크
- 비밀번호 강도 확인
  - 8자 이상
  - 영문, 숫자, 특수문자 조합
- 비밀번호 일치 확인

## 2. 프로필 관리

### 2.1 프로필 조회

#### 표시 정보
- 프로필 이미지
- 닉네임
- 이메일
- 가입일
- 활동 통계

#### 화면 구성
```
┌─────────────────┐
│   프로필 이미지   │
├─────────────────┤
│   닉네임          │
│   이메일          │
│   가입일: YYYY-MM-DD │
├─────────────────┤
│   게시글: 15     │
│   팔로워: 120    │
│   팔로잉: 85     │
└─────────────────┘
```

### 2.2 프로필 수정

#### 수정 가능 항목
- [x] 프로필 이미지
- [x] 닉네임
- [x] 자기소개
- [x] 웹사이트 URL
- [ ] 이메일 (별도 인증 필요)

#### 이미지 업로드
- 지원 형식: JPG, PNG, WEBP
- 최대 크기: 5MB
- 권장 크기: 400x400px
- 자동 리사이징 및 최적화

## 8. 데이터 구조

### 8.1 사용자 (User)
```typescript
interface User {
  id: string;
  email: string;
  nickname: string;
  profileImage?: string;
  bio?: string;
  website?: string;
  createdAt: Date;
  updatedAt: Date;
}
```

### 8.2 게시글 (Post)
```typescript
interface Post {
  id: string;
  authorId: string;
  title: string;
  content: string;
  images?: string[];
  tags?: string[];
  likes: number;
  comments: number;
  createdAt: Date;
  updatedAt: Date;
}
```

### 8.3 알림 (Notification)
```typescript
interface Notification {
  id: string;
  userId: string;
  type: 'system' | 'activity';
  title: string;
  message: string;
  read: boolean;
  actionUrl?: string;
  createdAt: Date;
}
```
